Review what your identity provider advertises: the flows it still allows, PKCE, signing algorithms, client authentication and the newer defenses. Checks run in this page.

Fetch from your provider

Your browser fetches /.well-known/openid-configuration from that issuer directly. Some providers block this; if so, paste the document below.

In a pipeline

The same file is a command-line tool. Run it on a schedule against your issuers to catch a setting someone turned back on. It exits 1 on errors.

node oidc-config-check.js https://login.example.com --fail-on warn
